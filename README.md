### Mo Ali's Portfolio

# Mo Ali - Software Developer Portfolio

This is a clean, minimalist, single-page portfolio website for Mo Ali, a Software Developer. It is built as a static site using pure HTML and CSS, designed to be lightweight and fully responsive.

The site serves as a personal landing page, introducing the developer, showcasing key projects, and providing contact information along with a downloadable CV.

## Features

  * **Responsive Design**: The layout adapts smoothly to desktop, tablet, and mobile screen sizes.
  * **Hero Section**: A full-screen landing area that introduces "Mo Ali" as a "Software Developer" and provides prominent links to social & professional profiles, including GitHub, LinkedIn, and Twitter.
  * **About Me**: A brief introduction featuring a personal photo (`Photo.png`) and high-level statistics:
      * "05 Years Experience"
      * "30+ Projects Completed"
      * "10+ Happy Clients"
  * **Portfolio Showcase**: A grid section displaying two featured projects:
      * E-commerce Website
      * Music Streaming App
  * **Contact Section**: A simple footer providing Email, Phone, and Location details for contact.
  * **CV Download**: A clear "Download CV" button that links directly to the `Resume.pdf` file.

## Technology Stack

  * **HTML5**
  * **CSS3** (Styles are embedded within the `index.html` file)

## How to View

No installation, server, or build process is required.

1.  Ensure all files (especially the `images` folder and `Resume.pdf`) are in the same directory as `index.html`.
2.  Open the `index.html` file in any modern web browser.

## File Structure

```
moali_portfolio/
```
